# FitMart

A Full Stack MERN E-Commerce Application for Fitness & Nutrition Products.

## 🚀 Repository
https://github.com/<your-github-username>/FitMart

## 📌 Features
- User Authentication (Firebase)
- Product Listing
- Shopping Cart
- Secure Razorpay Payment Integration
- Order Management
- Admin Dashboard
- User Profile
- Workout Tracker
- AI Fitness Chatbot
- MongoDB Database

## 🛠️ Tech Stack
- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Firebase Authentication
- Tailwind CSS
- Razorpay
- Google Gemini AI

## 📂 Project Structure
```
FitMart/
├── client/

├── README.md

```

## ▶️ Installation

```bash
git clone https://github.com/<your-github-username>/FitMart.git
cd FitMart
npm install
```

### Run Backend

```bash
cd server
npm install
npm run dev
```

### Run Frontend

```bash
cd client
npm install
npm run dev
```
